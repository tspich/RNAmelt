1. Using the tool in the browser

The browser interface runs the full analysis pipeline locally via Pyodide (CPython compiled to WebAssembly). Your data never leaves your machine — there is no server, no upload.

CSV format

Column 0 is temperature in °C (any header name). Columns 1+ are signal columns — absorbance or fluorescence. Rows where temperature is missing or all values are NaN are dropped.

temperature, sample_1, sample_2, sample_3
20.0,        0.412,    0.388,    0.401
20.5,        0.415,    0.391,    0.404
...

Workflow

  1. Drag & drop a CSV onto the upload zone — or click to browse.
  2. Choose the structure type: Heterodimer (two different strands), Homodimer (self-complementary) or Monomer (hairpin).
  3. Pick a signal column, or one of the multi-column modes: multi (shared ΔH fit) or concentration series.
  4. Enter the oligo concentration CT in µM — per strand, required for dimers. In the multi-column modes each column gets its own CT pill.
  5. Check the baseline windows (see below). Each curve's windows are detected automatically the first time you open it; adjust them if needed.
  6. Click ▶ Run analysis. Three Tm estimates are returned: raw (baseline intersection), van't Hoff linearisation, and the full non-linear two-state fit.

If an analysis fails — for example when the fit cannot place the transition inside the fitted temperature range — the reason is shown instead of numbers. Adjust the baseline windows and run again.

Baseline windows

Four temperatures (°C) define the analysis, set with the four-handle slider or typed into the boxes:

WindowRangeUsed for
Folded baseline[foldlo, foldhi]linear fit of the low-temperature plateau
Unfolded baseline[unflo, unfhi]linear fit of the high-temperature plateau
Fit window[foldlo, unfhi]data used by the full two-state fit
  • Every curve gets its own windows. They are detected automatically the first time a curve is shown: the first column on file load, each column when you select it, and every curve when you enter a multi-column mode. Windows you have set are kept when you come back to a curve.
  • If detection fails, windows at the scan edges are used and an amber warning names the curve. Check those windows; the warning disappears once you edit them.
  • ⚙ Auto detect re-detects the curve being edited. In the multi-column modes, ⚙ Detect all baselines re-detects every curve; click a CT pill to inspect or edit that curve's windows. When re-detection fails, windows you already had are kept.

Advanced settings

The collapsible Advanced section holds one set of analysis settings used for every curve. A blank field means the default, shown greyed out.

SettingDefaultEffect
van't Hoff border0.15Fraction of θ trimmed at each end of the van't Hoff regression; larger keeps fewer, more central points (0–0.5).
lin_init10Number of first / last points averaged to seed the baseline intercepts of the fit.
ΔH start, ΔS startvan't HoffStarting values of the non-linear fit (folding, so negative). ΔS is in cal/(mol·K), like the results. A value you leave blank comes from the van't Hoff estimate.
Baseline slopesphysicalphysical: slopes capped from the data · loose: folded slope ≥ 0 · positive: both ≥ 0 · unbounded: free.
Fit strategysinglemultistart runs one fit per ΔH seed and keeps the best — slower, but more robust for hard curves. Not used by the multi (shared ΔH) fit.

Invalid values are reported instead of being silently corrected.

Reset to defaults & Clear

  • ↺ Reset to defaults re-detects the windows of the curve being edited, empties the Advanced section, and re-runs. CT values are kept.
  • ✕ Clear removes everything — data, concentrations, windows, Advanced settings, results — and returns to the upload screen. It asks for confirmation first.

Three analysis modes

ModeColumn dropdownWhat it does
Single column any signal column Tm by baseline intersection, van't Hoff linearisation, and a full two-state non-linear fit. Returns ΔH / ΔS / ΔG / Tm from each method.
Shared-ΔH multi multi (shared ΔH fit) Joint fit across all columns sharing ΔH and ΔS, with independent baselines per column. Each column carries its own concentration.
Concentration series concentration series Extracts three Tm values per column (raw / vH / full fit) and fits 1/Tm = (R/ΔH)·ln(C_T/f) + ΔS/ΔH for each. f = 1 for homodimers, f = 4 for heterodimers. Not applicable to monomers, whose Tm does not depend on concentration.

All three plots (melting curve, van't Hoff / concentration regression, derivative) are interactive:

Zooming and panning act on both axes simultaneously. The shaded baseline-window overlay on the melting-curve plot follows the zoom — useful for inspecting the baseline regions or the steep part of the transition without re-running the fit.

Download results

⬇ Download results CSV saves a results file containing a per-column block (raw / vH / full-fit / multi columns) and, for concentration mode, an additional block with the per-curve table and the three regressions. ⬇ Download plots (SVG) saves each visible chart as a vector SVG image, as shown, including the current zoom. SVG files open in Inkscape, Illustrator or a browser, and stay sharp at any size. Text uses standard system fonts, so tick labels can look slightly different from the page.

2. Python API

The browser runs the rnamelt Python package; the same analyses are available as a library:

pip install rnamelt              # base — numpy / pandas / scipy
pip install 'rnamelt[plots]'     # also pulls matplotlib for rnamelt.plots

SingleCurve — one melting curve

import pandas as pd
from rnamelt import SingleCurve

df = pd.read_csv("melt.csv")
T  = df.iloc[:, 0].to_numpy(float)

c = SingleCurve(
    T, df["sample_1"].to_numpy(float),
    name="sample_1",
    oligoC=0.5,                   # per-strand concentration, µM (required for dimers)
    struct_type="heterodimer",    # "heterodimer" | "homodimer" | "monomer"
)

r  = c.raw_tm()      # RawTm      — Tm where the mean baseline crosses the data
vh = c.vant_hoff()   # VanHoffFit — linear fit of ln K vs 1/T
f  = c.fit()         # SingleFit  — non-linear fit of the full two-state model

if f.ok:
    print(f.dH, f.dS, f.dG, f.Tm)
else:
    print(f.error)

Data and concentration are all a default run needs. Baseline windows are detected automatically, and the fit is seeded from the van't Hoff estimate.

Baseline windows

c = SingleCurve(T, signal, oligoC=0.5,
                fold_low_T=15, fold_high_T=35, unf_low_T=70, unf_high_T=90)

Give all four temperatures or none; they must satisfy fold_low_T < fold_high_T ≤ unf_low_T < unf_high_T. When omitted they are detected (c.window_source == "auto"); if detection fails, edge windows of windows["fallback_width"] °C are used and a BaselineWarning is issued ("fallback"). c.auto_baselines() returns the detected windows without changing the curve.

MultiCurves — several curves

from rnamelt import SingleCurve, MultiCurves

oligos = {"s1": 0.5, "s2": 5.0, "s3": 50.0}
m = MultiCurves([SingleCurve(T, df[col].to_numpy(float), name=col, oligoC=o)
                 for col, o in oligos.items()])

gf = m.global_fit()          # GlobalFit — shared ΔH/ΔS, baselines per curve
gf.dH, gf.dS, gf.dG
for cc in gf.curves:         # GlobalFitCurve
    print(cc.name, cc.oligoC, cc.Tm)

cdr = m.conc_dependency()    # ConcDepResult — 1/Tm vs ln(C_T/f)
for s in (cdr.series_raw, cdr.series_vh, cdr.series_fit):
    if s.ok:
        print(s.method, s.dH, s.dS, s.dG, s.r_squared)
cdr.per_curve, cdr.skipped

Each curve keeps its own concentration, windows and settings, and curves may differ in length. All curves must share one struct_type.

Settings

Every tunable default lives in one dict exported from rnamelt:

ArgumentDefaultsControls
windowsWINDOW_DEFAULTSdetector options for baseline detection, fallback_width
solverSOLVER_DEFAULTSscipy.optimize.least_squares options: max_nfev, tolerances, loss, f_scale, x_scale, …
vhVH_DEFAULTSvan't Hoff: border (θ range kept), t1_min / t1_max, T_scale
fit_initFIT_INIT_DEFAULTSstarting values: seed_from, dH_init, dS_init, lin_init, b1_init, b2_init, fallbacks and plausible ranges
boundsBOUNDS_DEFAULTSmode (baseline slopes: physical · loose · positive · unbounded), dH / dS boxes, slope_cap_k, Tm_margin
multistartMULTISTART_DEFAULTSdH_seeds, fwhm_factors, seed_Tm_K, min_abs_dH
rawRAW_DEFAULTSedge_skip for the raw-Tm crossing search

Pass a partial dict per curve (validated when the curve is built — typos raise ValueError) or per call (applies to that call only):

c = SingleCurve(T, signal, oligoC=0.5, vh={"border": 0.2}, bounds={"mode": "loose"})

c.fit(solver={"max_nfev": 500})
c.fit(bounds_mode="unbounded")          # shortcut for bounds={"mode": ...}
c.fit(strategy="multistart")            # one fit per dH seed, lowest RMS wins
c.vant_hoff(vh={"t1_min": 2.9, "t1_max": 3.1})

m.conc_dependency(fit_init={"seed_from": "user", "dH_init": -100, "dS_init": -0.28})
m.global_fit(bounds={"dH": (-250, 0)})

In global_fit, the settings that define the shared ΔH/ΔS — the solver, seed_from, and the dH/dS starting values, fallbacks and boxes — must agree across curves. A conflict raises ValueError naming the setting; passing it in the call resolves it.

Starting values

The dH / dS starting values follow fit_init["seed_from"]:

seed_fromStarting values
"auto"your dH_init / dS_init where given, else van't Hoff, else the fallbacks
"vh"van't Hoff, else the fallbacks (ignores dH_init / dS_init)
"user"dH_init and dS_init (both required)
"fallback"dH_fallback / dS_fallback, without running van't Hoff

The van't Hoff dH and dS are used as a pair: if either falls outside its plausible range, both fall back. SingleFit.seed and GlobalFit.seed report the values used and where each came from.

Results

Every analysis returns a NamedTuple from rnamelt.results: RawTm, VanHoffFit, SingleFit, GlobalFit (holds GlobalFitCurves) and ConcDepResult (holds ConcentrationCurves and three ConcentrationSeries). A failed analysis is returned, not raised: ok is False and error says why — check ok before reading values.

  • converged = False: the solver stopped at max_nfev. The best result is returned anyway, with a ConvergenceWarning.
  • A fit whose model Tm lies more than bounds["Tm_margin"] (3 °C) outside the fitted temperature range did not find the transition and is returned with ok = False.

Units: ΔH in kcal/mol, ΔS in kcal/(mol·K), ΔG in kcal/mol at 37 °C, Tm in °C (ConcentrationCurve also gives Tm_*_K in K), CT (c0) in M, oligoC in µM, baselines as (slope, intercept).

Plotting (optional — needs matplotlib)

matplotlib is only imported by rnamelt.plots, so the browser bundle never loads it.

from rnamelt import plots

fig, axes = plots.plot_single(c)                       # raw / van't Hoff / fit
fig, ax   = plots.plot_multi(m.global_fit())
fig, axes = plots.plot_concentration(m.conc_dependency())

3. Two-state model

The observed signal is a mix of the folded and unfolded baselines, weighted by the folded fraction θ(T):

A(T) = (m1·T + b1)·θ + (m2·T + b2)·(1 − θ)
ΔG = ΔH − T·ΔS, K = exp(−ΔG / RT)
θ = K / (1 + K)     (monomer)
θ = (s − 1) / (s + 1), s = √(1 + 2·CT·K)     (heterodimer)
θ = (s − 1) / (s + 1), s = √(1 + 8·CT·K)     (homodimer)
Tm = ΔH / (ΔS + R·ln(CT/f)), f = 4 (hetero), 1 (homo); Tm = ΔH / ΔS (monomer)

ΔH, ΔS and ΔG refer to folding, so ΔH and ΔS are negative for a stable duplex. CT is the total strand concentration: 2 × the per-strand concentration for a heterodimer, 1 × for a homodimer.

Units: ΔH in kcal/mol, ΔS in kcal/(mol·K), ΔG in kcal/mol at 37 °C. Tm is reported in °C; the model works in K (T_K = T_C + 273.15).
